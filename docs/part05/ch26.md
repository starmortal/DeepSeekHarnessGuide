## 本章目标

这一章带你用 dsh 生成一段完整的视频。我们装一个 Remotion 视频创作插件，然后给它一个主题，让它从脚本到动画到字幕到配音全部搞定，最后渲染成 MP4。做完这一章，你会知道怎么让 dsh 帮你做视频，以及拿到初稿后怎么微调、怎么导出。

## 用什么插件：dsh-remotion

这一章用 **dsh-remotion**——一个把 Remotion 官方技能移植到 dsh 的视频创作插件，MIT 开源，[GitHub 仓库](https://github.com/STARDUSTLC666/dsh-remotion)。

Remotion 是一个用 React 编程式做视频的框架——写代码就能生成动画、字幕、转场，最后渲染成 MP4。dsh-remotion 把 Remotion 官方的 38 个规则文件（动画、音频、字幕、3D、图表、字体、转场等）注册进 dsh，装好之后直接说"用 Remotion 做个视频"就能触发。

## 第 1 步：安装插件

本次通过 CH 17 装的插件市场（dsh-market）可视化安装——打开设置 → 插件市场，搜索 remotion，找到 dsh-remotion，点安装就行：

![插件市场搜索 dsh-remotion](/assets/part05/ch26-install.png)

点安装后，插件市场会显示"已安装"，顶部提示需要重启 dsh 才能生效——点"立即重启"就行：

![dsh-remotion 安装成功，提示重启生效](/assets/part05/ch26-extra.png)

重启后插件就生效了。

> 环境要求：Node.js ≥ 20；渲染视频需要 ffmpeg（Remotion 会自带指引安装）。

## 第 2 步：了解视频生成流程

装好之后，可以先让 dsh 简单介绍一下用 Remotion 做视频的流程，做到心里有数。直接问：

```
给我简单介绍一下用 Remotion 做视频的流程
```

它会告诉你用 Remotion 做视频的典型流程：**写脚本和分镜 → 创建 Remotion 项目 → 编写 Composition 和 React 组件 → 加动画、字幕、音频 → 预览调试 → 渲染 MP4**。Remotion 的核心概念是 Composition（注册一个视频片段，指定宽高、帧率、总帧数）、Sequence（时间轴，把组件按时间排好）、interpolate / spring（动画），最后用 `npx remotion render` 渲染输出。

![dsh 介绍 Remotion 视频生成流程](/assets/part05/ch26-flow.png)

## 第 3 步：给个主题，生成视频

做视频之前，先想好主题。这一章我们做一段 **"一切皆插件：DeepSeek Harness 一分钟介绍"** 的短视频。

提示词不需要写得很复杂，给个主题和时长就行，剩下的分镜、脚本、动画它会自己规划：

```
用 Remotion 帮我做一段介绍视频，主题是"一切皆插件：DeepSeek Harness 入门介绍"，面向第一次接触 dsh 的开发者。

要求：
- 风格简约白，动画演示感
- 带字幕和配音（中文配音）
- 包含动画效果（文字浮现、元素过渡）
- 包含转场效果（场景之间用不同转场）
- 包含图表（比如用一个简单的架构图展示 dsh 的插件分层）
- 字体用等宽字体，符合技术主题
- 最后渲染成 MP4

如果缺少 ffmpeg 等渲染依赖，自己安装好再继续。
```

把这段话发给 dsh。它会按 Remotion 的流程一步步来——先写脚本和分镜，再创建 Remotion 项目，写 React 组件，加动画、字幕和配音，最后渲染。

下面是生成完成后的结果总结——实现要点、五幕结构、用到的技术都列得清清楚楚：

![生成完成：实现要点总结](/assets/part05/ch26-video1.png)

从发提示词到拿到渲染好的 MP4，全程 36 分 50 秒——视频渲染比做 PPT 慢，因为每一帧都要计算。这还只是随手给个主题的效果，有了插件把流程固化下来，dsh 照着步骤一步步跑，不用每次从零摸索该先做什么：

![生成完成：五幕结构与用时](/assets/part05/ch26-video2.png)
