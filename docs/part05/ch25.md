## 本章目标

这一章带你用 dsh 生成一份完整的 PPT。我们装一个专门做 PPT 的 Skill，然后给它一份材料，让它从大纲到排版到生成网页版 PPT 全部搞定，最后还能在浏览器里直接编辑、导出可编辑的 PPTX。做完这一章，你会知道怎么让 dsh 帮你做演示文稿，以及拿到初稿后怎么微调、怎么导出。

## 用什么 Skill：dashiai-ppt

这一章用 **dashiai-ppt**——一个面向职场人的 PPT Skill，AGPL-3.0 开源，[GitHub 仓库](https://github.com/chuspeeism/dashiAI-ppt-skill)。

它的特点：

- **12 套视觉主题**：轻拟态、炫光紫绿、深浅代码、玻璃糖果、黑金实验、深蓝杂志、高能增长等，做不同类型的汇报选不同风格
- **1020 个版式页面**：几十种图表、SWOT / 波特五力 / 商业模式画布等分析模型、架构图、时间线、图文画廊——做汇报真正会用到的页面都有现成版式
- **生成后可编辑**：每一页都带控制台，改文字、换图片、调模块数量、换配色，改动自动保存回文件
- **可导出 PPTX**：不是图片，是真正可编辑的 PowerPoint 文件，文字框、图表都能手动改
- **全部本地运行**：生成、编辑、导出都在本机完成，内容不上传服务器

## 第 1 步：安装 Skill

这个 Skill 的完整内容在 GitHub 仓库的 `skills/dashiai-ppt/` 子目录里，我们用"直接放文件夹"的方式装到 dsh 的项目级 Skill 目录 `<项目根>/.dsh/skills/` 下，不按 README 里的 npx 命令装。

在 dsh 里直接说：

```
帮我安装 dashiai-ppt 这个 PPT skill，仓库地址是 https://github.com/chuspeeism/dashiAI-ppt-skill，skill 内容在仓库的 skills/dashiai-ppt/ 子目录。把这个子目录克隆到当前工作区的 .dsh/skills/ 下，装好后告诉我。
```

dsh 会自己克隆仓库、把 skill 文件夹放到正确的位置。

![安装 dashiai-ppt skill 成功](/assets/part05/ch25-skill-install.png)

> 环境要求：本机能运行 Node.js 18+ 和 npm（首次生成时依赖自动安装）；导出 PPTX / PDF 需要本机装有 Chrome / Edge。

## 第 2 步：了解 Skill 的工作流程

装好之后，可以先让 dsh 简单介绍一下这个 skill 的流程，做到心里有数。直接问：

```
给我简单介绍一下这个skill的流程
```

它会告诉你完整的工作流：**一问风格 → 定内容 → 生成 JSON 计划 → 渲染 HTML → 校验验收 → 交付**。简单说就是：你给需求，它确认风格和素材，生成方案，本地渲染，预览校验，按格式交付。全程本地完成、离线可用。

![dashiai-ppt skill 工作流程介绍](/assets/part05/ch25-step2.png)

## 第 3 步：给个主题，生成 PPT

做 PPT 很灵活：如果你手头已经有材料（比如一份文档、一篇文章、一组数据），可以直接把材料丢给 dsh，让它基于那份材料做 PPT；如果还没有现成材料，只给一个主题也行，dsh 会自己规划内容结构，一步步跟你确认。

我们这里演示只给主题的方式。这一章我们做一份 **"一切皆插件：DeepSeek Harness 入门指南"** 的分享 PPT。

```
用 dashiai-ppt 帮我做一份 PPT，主题是"一切皆插件：DeepSeek Harness 入门指南"，面向第一次接触 dsh 的开发者。
```

把这段话发给 dsh。它会按 skill 的流程一步步跟你确认风格、页数、内容结构，然后调用生成器渲染，最后给你一个本地预览链接。

这就是 Skill 的好处——它把"做 PPT"这件事的完整流程固化成了一套清晰的步骤，dsh 照着走就行，不用每次都从零摸索该先问什么、再做什么。下面是它遵循 skill 规范进行生成的过程——先确认主题风格，再规划内容结构，再逐页生成：

![生成流程一：确认风格与内容规划](/assets/part05/ch25-gen-flow1.png)

![生成流程二：逐页生成内容](/assets/part05/ch25-gen-flow2.png)

![生成流程三：渲染完成交付预览](/assets/part05/ch25-gen-flow3.png)

生成过程中如果需要安装依赖（比如首次运行时 npm 装包），dsh 会自动放到后台执行，不阻塞主任务进度。下图就是后台安装依赖的同时，主对话还在继续推进：

![后台安装依赖不阻塞主任务](/assets/part05/ch25-bg-install.png)

这里能看到后台任务的执行过程，是因为 CH 17 装了 dsh-better-sidebar 侧边栏插件——它会自动展开，把后台正在跑的任务主动展示出来。没有这个插件的话，dsh 同样会在后台执行、同样可以在轨迹里追踪查找到，但你不主动去翻轨迹就看不到发生了什么。有了侧边栏，后台干了什么一目了然。

生成完成后，dsh 会给你一个本地预览地址，同时附上成品概况——主题、风格、页数、产出格式、页面大纲都列得清清楚楚：

从发提示词到拿到 12 页完整 PPT，全程 17 分 27 秒。这还只是随手给个主题的效果——有了 Skill 把流程固化下来，dsh 照着步骤一步步跑，不用每次从零摸索该先做什么：

DeepSeek 作为国产模型，本身定价就很实惠，再加上 dsh 的高缓存命中技术——多轮对话里系统提示、工作区配置、历史对话这些前缀几乎不变，每次都能命中缓存，命中的那部分输入按远低于正常价格计费。两者叠加下来，跑一个完整的 Agent 任务成本极低，日常用完全不心疼。

## 第 4 步：在浏览器里编辑

生成完成后，dsh 会给你一个本地网页链接（类似 `http://127.0.0.1:端口号/`），在浏览器里打开就是网页版 PPT 编辑器。

每一页都带控制台，你可以：

- **改文字**：点击任意文字直接编辑
- **换图片**：点击图片槽位上传替换
- **调模块数量**：拖滑杆增减页面里的模块
- **换布局**：在控制台里选不同版式
- **换配色**：风格内配色一键切换
- **翻页动画**：9 种切换动画可选

改动会自动保存回文件。不满意的地方直接改，改完刷新就是最新效果。

下图就是浏览器里打开的 PPT 编辑器——左侧是 12 页缩略图目录，中间是当前页，右侧是控制台，页面版式、切换动画、主题色、模块数量都能直接调：

![浏览器里的 PPT 编辑器](/assets/part05/ch25-extra2.png)

文字也能直接在线编辑——点击任意文字区域就能改，改完自动保存，不用回到 dsh 重新生成：

![在线直接编辑文字](/assets/part05/ch25-export2.png)

## 第 5 步：导出 PPTX

满意后，在浏览器右上角的导出菜单里选 PPTX，就能下载一份真正可编辑的 PowerPoint 文件。导出菜单里还支持 HTML 离线包和 PDF：

![导出菜单：HTML / PDF / PPTX](/assets/part05/ch25-export1.png)

也可以让 dsh 直接导出：

```
把刚才生成的 PPT 导出成 .pptx 文件，放到当前工作区，文件名 deepseek-harness-intro.pptx。
```

文件会落在工作区里，双击就能用 PowerPoint 或 WPS 打开继续编辑。
