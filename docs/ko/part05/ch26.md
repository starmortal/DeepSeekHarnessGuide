## 본 장의 목표

이 장에서는 dsh를 사용해 완전한 PPT 한 개를 생성합니다. PPT 전용 Skill을 하나 설치한 다음, 소재를 던져 주기만 하면 outline부터 layout, 웹 버전 PPT 생성까지 모두 알아서 처리해 줍니다. 게다가 브라우저에서 직접 편집하고 편집 가능한 PPTX로 내보낼 수도 있습니다. 이 장을 마치면 dsh를 활용해 프레젠테이션을 만드는 방법과, 초안을 받은 뒤 미세 조정하고 내보내는 방법을 알게 됩니다.

## 어떤 Skill인가: dashiai-ppt

이 장에서는 **dashiai-ppt**를 사용합니다 — 직장인을 위한 PPT Skill로, AGPL-3.0 오픈소스이며 [GitHub 저장소](https://github.com/chuspeeism/dashiAI-ppt-skill)에서 확인할 수 있습니다.

이 Skill의 특징은 다음과 같습니다.

- **12가지 비주얼 테마**: 소프트 스큐어모피즘, 네온 퍼플-그린, 라이트/다크 코드, 글래스 캔디, 블랙-골드 실험, 딥블루 매거진, 하이에너지 성장 등. 보고서 유형에 따라 다른 스타일을 선택할 수 있습니다.
- **1020개 레이아웃 페이지**: 수십 종의 차트, SWOT / Porter's Five Forces / Business Model Canvas 같은 분석 모델, 아키텍처 다이어그램, 타임라인, 이미지-텍스트 갤러리 — 보고에 실제로 필요한 페이지는 모두 준비된 레이아웃을 갖추고 있습니다.
- **생성 후 편집 가능**: 각 페이지에 콘솔이 있어, 텍스트 수정, 이미지 교체, 모듈 개수 조정, 색상 변경이 가능하며, 변경 사항은 자동으로 파일에 저장됩니다.
- **PPTX로 내보내기 가능**: 이미지가 아니라 실제로 편집 가능한 PowerPoint 파일이며, 텍스트 박스와 차트는 수동으로 수정할 수 있습니다.
- **모두 로컬에서 실행**: 생성·편집·내보내기를 모두 로컬에서 처리하므로 콘텐츠가 서버로 업로드되지 않습니다.

## 1단계: Skill 설치하기

이 Skill의 전체 내용은 GitHub 저장소의 `skills/dashiai-ppt/` 하위 디렉터리에 들어 있습니다. README에 적힌 npx 명령이 아니라, "폴더째 직접 복사" 방식으로 dsh의 프로젝트 레벨 Skill 디렉터리인 `<프로젝트 루트>/.dsh/skills/` 아래에 설치합니다.

dsh에서 바로 다음과 같이 말합니다.

```
Help me install the dashiai-ppt PPT skill; the repo is https://github.com/chuspeeism/dashiAI-ppt-skill, the skill content is in the repo's skills/dashiai-ppt/ subdirectory. Clone this subdirectory to the .dsh/skills/ under the current workspace, and tell me when it's done.
```

dsh가 저장소를 직접 clone하여 skill 폴더를 올바른 위치에 둡니다.

![dashiai-ppt skill 설치 성공](/assets/part05/ch25-skill-install.png)

> 환경 요구 사항: 로컬 컴퓨터에서 Node.js 18+ 및 npm 실행 가능(첫 생성 시 의존성이 자동으로 설치됨). PPTX / PDF 내보내기를 위해서는 로컬에 Chrome / Edge가 설치되어 있어야 합니다.

## 2단계: Skill의 작업 흐름 이해하기

설치 후, 먼저 dsh에게 이 skill의 흐름을 간략히 소개시켜 보세요. 그래야 진행할 내용을 미리 알 수 있습니다. 다음과 같이 직접 묻습니다.

```
Briefly introduce the flow of this skill
```

그러면 전체 작업 흐름을 알려 줍니다. **스타일 묻기 → 콘텐츠 확정 → JSON 계획 생성 → HTML 렌더링 → 합격 검증 → 납품**. 쉽게 말해, 사용자가 요구 사항을 주면 skill이 스타일과 자원을 확인하고, 계획을 생성한 뒤 로컬에서 렌더링하고, 미리 보기로 검증한 뒤, 정해진 형식으로 결과를 전달합니다. 모든 과정이 로컬에서 진행되며 오프라인 사용도 가능합니다.

![dashiai-ppt skill 작업 흐름 소개](/assets/part05/ch25-step2.png)

## 3단계: 주제를 주어 PPT 생성하기

PPT 제작은 매우 유연합니다. 이미 자료(예: 문서 한 건, 글 한 편, 데이터 한 묶음)가 있다면 그 자료를 dsh에게 그대로 던져 주고, 그 자료를 기반으로 PPT를 만들도록 시킬 수 있습니다. 아직 자료가 없다면 주제만 던져 주어도 됩니다. dsh가 콘텐츠 구조를 직접 설계하고, 단계별로 사용자와 확정한 뒤 진행합니다.

여기서는 주제만 던지는 방식을 시연합니다. 이번 장에서 만들 PPT는 **"모든 것은 플러그인: DeepSeek Harness 입문 가이드"** 입니다.

```
Use dashiai-ppt to make a PPT for me, topic is "Everything is a Plugin: DeepSeek Harness Getting Started Guide", aimed at developers first encountering dsh.
```

이 메시지를 dsh에게 보냅니다. dsh는 skill의 흐름에 따라 스타일, 페이지 수, 콘텐츠 구조를 차례로 사용자와 확정한 뒤, 생성기를 호출하여 렌더링하고, 마지막에 로컬 미리 보기 링크를 알려 줍니다.

이것이 Skill의 장점입니다 — "PPT 만들기" 작업의 전체 흐름을 명확한 단계 집합으로 고정한 덕분에, dsh는 그 순서대로 따라 갈 뿐이며 매번 무엇을 먼저 물어야 하는지, 무엇을 다음에 해야 하는지를 처음부터 고민할 필요가 없습니다. 아래는 skill 명세를 따라 생성되는 과정입니다 — 먼저 테마 스타일을 확인하고, 콘텐츠 구조를 설계한 뒤, 페이지별로 생성합니다.

![생성 흐름 1: 스타일 및 콘텐츠 설계 확정](/assets/part05/ch25-gen-flow1.png)

![생성 흐름 2: 페이지별로 콘텐츠 생성](/assets/part05/ch25-gen-flow2.png)

![생성 흐름 3: 렌더링 완료 후 미리 보기 전달](/assets/part05/ch25-gen-flow3.png)

생성 과정에서 의존성 설치가 필요할 경우(예: 첫 실행 시의 npm install), dsh는 이를 자동으로 백그라운드에서 실행하여 메인 작업의 진행을 막지 않습니다. 아래 그림은 백그라운드에서 의존성을 설치하는 동안 메인 대화가 계속 진행되는 모습입니다.

![백그라운드 의존성 설치가 메인 작업을 막지 않음](/assets/part05/ch25-bg-install.png)

여기서 백그라운드 작업의 실행 과정을 볼 수 있는 이유는 CH 18에서 설치한 dsh-better-sidebar 사이드바 플러그인 덕분입니다 — 이 플러그인은 자동으로 펼쳐서 백그라운드에서 무엇이 진행되고 있는지 능동적으로 보여 줍니다. 이 플러그인이 없더라도 dsh는 동일하게 백그라운드에서 실행되며 trajectory에서도 동일하게 추적·조회할 수 있지만, 사용자가 직접 trajectory를 열어 보지 않는 한 무슨 일이 일어나고 있는지 알 수 없습니다. 사이드바 플러그인이 있으면 백그라운드에서 무엇이 일어나고 있는지 한눈에 보입니다.

생성이 완료되면 dsh는 로컬 미리 보기 URL을 알려 주고, 그와 동시에 결과물 개요를 함께 제공합니다 — 주제, 스타일, 페이지 수, 출력 형식, 페이지 outline까지 모두 정리해서 보여 줍니다.

![생성 완료: 미리 보기 URL 및 결과물 개요](/assets/part05/ch25-extra1.png)

프롬프트를 보내고 12페이지짜리 완전한 PPT를 받기까지 총 17분 27초가 걸렸습니다. 이것은 그저 주제를 막 던져 본 결과입니다 — Skill이 흐름을 고정한 덕분에, dsh는 그 단계들을 차례로 따라 갈 뿐이며 매번 무엇을 먼저 해야 할지를 처음부터 고민할 필요가 없습니다.

![생성 완료: 소요 시간 및 결과물 위치](/assets/part05/ch25-result.png)

비용은 얼마가 들었는지 살펴봅시다. 이번 PPT 제작에는 API 요청 124회, 1,061만 token이 사용되었으며, 비용은 ¥1.17입니다.

![DeepSeek Open Platform 사용량 정보](/assets/part05/ch25-cost.png)

DeepSeek는 국산 모델로 가격이 매우 저렴한 데다, dsh의 높은 캐시 적중 기술이 더해집니다 — 다회 대화에서 시스템 프롬프트, 작업 영역 설정, 기존 대화 이력 같은 prefix는 거의 변하지 않기 때문에 매번 캐시를 적중할 수 있고, 적중된 부분의 입력은 정상 가격보다 훨씬 낮은 요율로 청구됩니다. 이 두 가지가 결합되어 완전한 Agent 작업 한 번을 돌리는 비용은 매우 낮아, 일상적으로 사용해도 부담이 전혀 없습니다.

## 4단계: 브라우저에서 편집하기

생성이 완료되면 dsh가 로컬 웹 링크(예: `http://127.0.0.1:포트번호/`)를 알려 주는데, 브라우저에서 열면 웹 버전 PPT 편집기가 나타납니다.

각 페이지에는 콘솔이 있어 다음과 같은 작업이 가능합니다.

- **텍스트 수정**: 임의의 텍스트를 클릭하여 직접 편집
- **이미지 교체**: 이미지 슬롯을 클릭하여 대체 이미지 업로드
- **모듈 개수 조정**: 슬라이더를 드래그하여 페이지 안의 모듈 개수 증감
- **레이아웃 변경**: 콘솔에서 다른 레이아웃 선택
- **컬러 스킴 변경**: 스타일 안에서 원클릭으로 전환
- **페이지 전환 애니메이션**: 9가지 전환 애니메이션 중 선택

변경 사항은 자동으로 파일에 저장됩니다. 만족스럽지 않은 부분은 그대로 수정하면 되고, 수정한 뒤 새로 고침하면 최신 결과가 보입니다.

아래 그림은 브라우저에서 열린 PPT 편집기입니다 — 왼쪽에는 12페이지의 썸네일 디렉터리가, 가운데에는 현재 페이지가, 오른쪽에는 콘솔이 있으며 페이지 레이아웃, 전환 애니메이션, 테마 색상, 모듈 개수를 모두 직접 조절할 수 있습니다.

![브라우저 안의 PPT 편집기](/assets/part05/ch25-extra2.png)

텍스트 역시 온라인에서 바로 편집할 수 있습니다 — 임의의 텍스트 영역을 클릭하면 수정되며, 수정 사항은 자동으로 저장되므로 dsh로 돌아가 재성성할 필요가 없습니다.

![온라인에서 텍스트 직접 편집](/assets/part05/ch25-export2.png)

## 5단계: PPTX로 내보내기

만족스러운 결과물이면 브라우저 우측 상단의 내보내기(export) 메뉴에서 PPTX를 선택하면 실제로 편집 가능한 PowerPoint 파일을 다운로드할 수 있습니다. 내보내기 메뉴는 HTML 오프라인 패키지와 PDF도 함께 지원합니다.

![내보내기 메뉴: HTML / PDF / PPTX](/assets/part05/ch25-export1.png)

다음과 같이 dsh에게 직접 내보내도록 시킬 수도 있습니다.

```
Export the PPT you just generated into a .pptx file, put it in the current workspace, filename deepseek-harness-intro.pptx.
```

파일은 작업 영역에 저장되며, 더블 클릭하면 PowerPoint 또는 WPS로 열어 계속 편집할 수 있습니다.

## 이 장에서 배운 것

아래 항목들을 스스로 완수할 수 있다면 합격입니다.

- [ ] dashiai-ppt skill을 프로젝트 레벨 `.dsh/skills/` 디렉터리에 설치할 수 있다
- [ ] dsh가 완전한 PPT를 생성하도록 만드는 프롬프트를 작성할 수 있다
- [ ] 브라우저 편집기에서 텍스트를 직접 수정하고, 이미지를 교체하고, 레이아웃을 조정하는 방법을 알고 있다
- [ ] `.pptx` 파일을 내보낸 뒤 PowerPoint로 열어 볼 수 있다
