## 본 장의 목표

이 장에서는 dsh를 사용해 완전한 영상 하나를 생성합니다. Remotion 영상 제작 플러그인을 설치한 뒤 주제를 던져 주기만 하면, 스크립트부터 애니메이션, 자막, 더빙까지 모두 알아서 처리하고 마지막에 MP4로 렌더링합니다. 이 장을 마치면 dsh를 활용해 영상을 만드는 방법과, 초안을 받은 뒤 미세 조정하고 내보내는 방법을 알게 됩니다.

## 어떤 플러그인인가: dsh-remotion

이 장에서는 **dsh-remotion**을 사용합니다 — Remotion의 공식 skills를 dsh로 이식한 영상 제작 플러그인으로, MIT 라이선스 오픈소스이며 [GitHub 저장소](https://github.com/STARDUSTLC666/dsh-remotion)에서 확인할 수 있습니다.

Remotion은 React로 프로그래밍 방식으로 영상을 만드는 프레임워크입니다 — 코드를 작성하여 애니메이션, 자막, 전환 효과를 생성하고, 마지막에 MP4로 렌더링합니다. dsh-remotion은 Remotion의 공식 룰 파일 38개(애니메이션, 오디오, 자막, 3D, 차트, 폰트, 전환 효과 등)를 dsh에 등록하므로, 설치 후에는 그냥 "Remotion으로 영상 하나 만들어 줘"라고만 말하면 트리거됩니다.

## 1단계: 플러그인 설치하기

이번에는 CH 17에서 설치한 플러그인 마켓(dsh-market)을 통해 설치합니다 — 설정 → 플러그인 마켓을 열고 remotion을 검색하여 dsh-remotion을 찾은 뒤, 설치를 클릭합니다.

![플러그인 마켓에서 dsh-remotion 검색](/assets/part05/ch26-install.png)

설치를 클릭하면 플러그인 마켓에 "설치됨"으로 표시되고, 상단에 dsh를 재시작해야 적용된다는 안내가 뜹니다 — "지금 재시작"을 클릭합니다.

![dsh-remotion 설치 성공, 재시작 후 적용 안내](/assets/part05/ch26-extra.png)

재시작이 끝나면 플러그인이 적용됩니다.

> 환경 요구 사항: Node.js ≥ 20. 영상 렌더링에는 ffmpeg가 필요합니다(Remotion이 설치 안내를 함께 제공합니다).

## 2단계: 영상 생성 흐름 이해하기

설치 후, 먼저 dsh에게 Remotion으로 영상을 만드는 흐름을 간략히 소개시켜 보세요. 그래야 진행할 내용을 미리 알 수 있습니다. 다음과 같이 직접 묻습니다.

```
Briefly introduce the flow of making videos with Remotion
```

그러면 Remotion으로 영상을 만드는 전형적인 흐름을 알려 줍니다. **스크립트와 스토리보드 작성 → Remotion 프로젝트 생성 → Composition 및 React 컴포넌트 작성 → 애니메이션, 자막, 오디오 추가 → 미리 보기 및 디버깅 → MP4 렌더링**. Remotion의 핵심 개념은 Composition(영상 구간을 등록하고, 너비/높이, 프레임 속도, 총 프레임 수를 지정), Sequence(타임라인, 컴포넌트를 시간 순으로 배치), interpolate / spring(애니메이션)이며, 마지막에 `npx remotion render`로 출력합니다.

![dsh가 소개하는 Remotion 영상 생성 흐름](/assets/part05/ch26-flow.png)

## 3단계: 주제를 주어 영상 생성하기

영상을 만들기 전, 먼저 주제를 정합니다. 이번 장에서 만들 영상은 **"모든 것은 플러그인: DeepSeek Harness 1분 소개"** 입니다.

프롬프트는 복잡하게 쓸 필요 없이 주제와 길이만 주면 됩니다. 나머지 스토리보드, 스크립트, 애니메이션은 dsh가 직접 설계합니다.

```
Use Remotion to make an intro video for me, topic is "Everything is a Plugin: DeepSeek Harness Intro", aimed at developers first encountering dsh.

Requirements:
- Style minimal white, animation demo feel
- With captions and voiceover (Chinese voiceover)
- Include animation effects (text fade-in, element transition)
- Include transition effects (use different transitions between scenes)
- Include charts (e.g. use a simple architecture diagram to show dsh's plugin layers)
- Use monospace font, fits the technical theme
- Finally render to MP4

If missing rendering dependencies like ffmpeg, install them yourself then continue.
```

이 메시지를 dsh에게 보냅니다. dsh는 Remotion의 흐름에 따라 차례로 — 먼저 스크립트와 스토리보드를 작성하고, 그 다음 Remotion 프로젝트를 만들어 React 컴포넌트를 작성하며, 애니메이션, 자막, 더빙을 추가한 뒤, 마지막에 렌더링합니다.

아래는 생성이 끝난 뒤의 결과 요약입니다 — 구현 요점, 5막 구성, 사용된 기술이 모두 정리되어 표시됩니다.

![생성 완료: 구현 요점 요약](/assets/part05/ch26-video1.png)

프롬프트를 보내고 렌더링된 MP4를 받기까지 총 36분 50초가 걸렸습니다 — 영상 렌더링은 PPT보다 느린데, 모든 프레임을 계산해야 하기 때문입니다. 이것은 그저 주제를 막 던져 본 결과입니다 — 플러그인이 흐름을 고정한 덕분에, dsh는 그 단계들을 차례로 따라 갈 뿐이며 매번 무엇을 먼저 해야 할지를 처음부터 고민할 필요가 없습니다.

![생성 완료: 5막 구성 및 소요 시간](/assets/part05/ch26-video2.png)
