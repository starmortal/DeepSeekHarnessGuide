## 본장 목표

이 장을 쓰기 전, 저는 dsh를 진지하게 이해할 가치가 있는지 한참 고민했습니다. Agent 프레임워크는 시장에 차고 넘치니, 하나쯤 더 있어도 별 의미 없다고 느끼기 쉽습니다. 그런데 막상 손을 대보니 dsh는 다른 것과 같은 범주가 아니었습니다. "또 하나의 즉시 사용 가능한 Agent 도구"가 아니라, **스스로 Agent를 조립하는 키트**입니다.

이 장에서는 명령을 치는 법을 가르치지 않습니다. 먼저 세 가지 직관을 세웁니다. 이 세 가지만 잡히면, 이후 모든 장에서 "지금 무엇을 하고 있는지"가 보일 것입니다.

1. **Agent란 무엇인가** — 공식 한 줄 공식: `Agent = Model + Harness`
2. **왜 "everything is a plugin"이라 하는가** — 여기서 말하는 "레고"의 의미
3. **왜 하필 "지금"인가** — 2026년 8월 13일 오픈소스 이후 무슨 일이 있었는가

## 실습

### 첫 번째 단계: 공식을 적어 둔다

DeepSeek 공식은 dsh의 포지셔닝을 한 문장으로 표현합니다.

```
Agent = Model + Harness
```

Model은 LLM 그 자체(DeepSeek-V4 시리즈든, 서드파티 모델이든)입니다. 오직 "생각"만 담당합니다. Harness는 Model을 제외한 모든 것——도구, 프롬프트, 메모리, 컨텍스트 관리, 작업 계획, 멀티 Agent 협업, MCP, Skill 등, Model이 실제로 **일을 해내게 하는** 껍질입니다.

비유하자면: **Model은 좋은 말, Harness는 고삐와 마구**입니다. 마구 없는 말은 아무리 빨라도 제자리에서 빙글빙글 돌기만 합니다. 마구를 차야 원하는 곳을 가리킬 수 있습니다.

한 줄 요약: **Model은 똑똑함을, Harness는 실행을 담당합니다.**

### 두 번째 단계: "레고"를 이해한다

dsh 공식 README의 첫 문장은 이렇습니다.

> It uses an architecture where **everything is a plugin**

모든 것이 플러그인. 풀어 말하면: Model 어댑터, 도구 레지스트리, 세션 로그, Agent 루프, UI, 메모리, 스케줄러——이 모든 것이 독립적인 플러그인 블록입니다. 설정에서 고르고, 바꾸고, 지우고, 더할 수 있으며, 프레임워크 소스를 한 줄도 건드릴 필요가 없습니다.

내부적으로는 **Cordis**라는 TypeScript 플러그인 시스템 위에서 동작합니다(공식에 따르면 4년 동안 다듬었다고 합니다). dsh의 한 줄 명령 뒤에는 90개가 넘는 플러그인이 쌓인 "플러그인 트리"가 있습니다. 아래 그림이 그 구조를 보여줍니다.

![dsh의 플러그인 트리 아키텍처(개념도)](/assets/part00/dsh-arch.svg)

이 그림에서 봐야 할 것은 두 가지뿐입니다.

1. **바닥은 Cordis** — 모든 플러그인은 Cordis 위에서 자라나며, Cordis가 이를 일괄 관리합니다.
2. **Agent 메인 루프조차 플러그인이다** — 가운데 형광 노란색 블록이 바로 그것입니다. 이것이 가장 파괴적인 지점: dsh에는 **코어도, 특권 경로도 없다**는 것. 기본 "생각-실행" 루프를 바꾸고 싶다? 프레임워크를 다시 쓰는 큰 공사가 아니라, 플러그인 하나를 교체하면 끝입니다.

이것이 "레고"입니다: 바닥은 고정, 그러나 어떤 모양이든 조립할 수 있습니다. 모델을 바꾸고 싶다? 플러그인 하나 교체. 도구를 추가하고 싶다? 플러그인 하나 설치. UI를 바꾸고 싶다? 스킨 플러그인 하나 설치. 그래서 "Agent의 레고 시대"라 부릅니다.

### 세 번째 단계: "왜 지금인가"를 본다

2026년 8월 13일 저녁, `deepseek-ai` 조직 아래에 새 리포지토리가 조용히 공개되었습니다. 리포지토리 설명은 단 한 줄——"Everything is a Plugin.". 발표회도 없고, 긴 홍보도 없으며, README에는 "앞으로 호환성을 깨는 변경이 있을 것"이라는 경고까지 적혀 있습니다.

그리고 숫자가 미친 듯이 뛰기 시작했습니다(아래는 모두 당시 미디어 실측 보도의 숫자이며, 공식 주장이 아닙니다).

- 오픈소스 **24시간** 만에 star **4.6만** 돌파(Hacker News 1위)
- 오픈소스 **48시간** 만에 star **10만** 돌파
- 오픈소스 **3일** 만에 star **13만** 초과, Fork 약 1.4만
- 플러그인 생태계: 공개 당일 실측 **288**개 리포지토리 등록 → 며칠 만에 `dsh-plugin` 태그 리포지토리 **1,000**개 초과 → 5일 만에 **6,000+**

왜 이렇게 폭발한 걸까요? 그때까지 Agent의 "신체 능력"——파일 접근, 터미널 실행, 도구 호출, 컨텍스트 구성——은 Claude Code, OpenAI Codex 같은 **클로즈드소스 제품 안에 용접되어** 있었기 때문입니다. 커스터마이징하려면? 벤더가 제공하는 플러그인 메커니즘(범위 제한)에 의존하거나, 처음부터 바퀴를 새로 만들거나 둘 중 하나였습니다. DeepSeek는 이번에 그 층 전체를 오픈소스로 공개하고, 그것을 레고 블록으로 분해해 공개한 것입니다.

## 이 장에서 배운 것

아래 세 가지를 스스로 할 수 있으면 합격입니다.

- [ ] `Agent = Model + Harness`를 자신의 말로 설명하고, Model과 Harness 각각의 역할을 말할 수 있다
- [ ] "교체 가능한" 부품을 최소 3개(예: 모델, 도구, UI, 메모리, 스케줄러) 거론하며, Agent 메인 루프조차 교체 가능하다는 것을 안다
- [ ] dsh가 언제(2026-08-13) 오픈소스화되었는지와 리포지토리 태그라인(Everything is a Plugin.)이 무엇인지를 말할 수 있다
