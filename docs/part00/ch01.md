## 本章目标

这一章不教你任何操作，只告诉你两件事：这本书怎么读，以及按什么节奏学。先选一条适合你的阅读路径，再照着三天学习计划走，心里有数就不会慌。

## 三条阅读路径

先看这张图，心里有个大概：

![三条阅读路径（示意）](/assets/part00/reading-paths.svg)

### 路线一：新手照读（推荐）

**适合谁**：第一次接触 dsh，从没跑过 Agent。

**怎么读**：从 CH 00 开始，一章一章往下读。PART 01（CH 02–07）一口气走完，先把"能跑起来"这关过了。然后读 CH 09"核心子系统与一条消息的流转"，再回头翻 CH 08 和 CH 10，你会有"原来如此"的感觉。

**为什么这样读**：前面的章节按真实任务组织，每一步都踩在下一步的脚底下。跳过会卡壳，卡壳再回来补更费劲。

### 路线二：场景直达

**适合谁**：知道自己要干什么，不想从头看。

**怎么读**：按下面的表直接跳：

| 你的目标 | 直接读 |
| --- | --- |
| 就想赶紧跑起来 | CH 03 → 04 → 05 |
| 想搞懂架构再动手 | CH 08 → 10 |
| 想接入 MCP 生态 | CH 12 |
| 想找现成插件装上用 | CH 12 → 17 |
| 想让 Agent 定时干活 | CH 15 |
| 想本地部署 | CH 16 |
| 想拿 dsh 做 PPT / 报表 / 视频 | CH 25 → 26 |
| 想开发自己的插件 | CH 18 → 20 → 21 |
| 想上生产 | CH 27 → 28 → 29 |

场景直达跳过的章节，卡住了再回来翻，不丢人。谁都不是一次读完的。

### 路线三：按需深入

**适合谁**：已经能把 dsh 跑起来了，拿它当工具书查。

**怎么读**：遇到问题翻目录找对应章节，配合附录。附录 A 术语表、附录 B 命令速查、附录 C 官方文档索引，是日常三件套。CH 07 排障速查值得单独收藏。

**特点**：不用顺序读，哪章卡就翻哪章。

## 三天学习路径

如果你想集中时间把 dsh 从头到尾过一遍，下面这个三天计划可以直接照做。每天的量按"边读边实操"设计，不是纯看文档。

### Day 1：跑起来，建立直觉

**目标**：把 dsh 装好用上，知道它能干什么。

**读什么**：CH 00 → CH 07（PART 00 + PART 01）

**做什么**：
1. CH 03 装好 Node.js 和 dsh，跑起 Web UI
2. CH 04 熟悉界面，选工作区、选模型、发第一条消息
3. CH 05 跑一次 headless，体验"没人盯着也能干活"
4. CH 06 接一个第三方模型（比如本地模型或另一家 API）
5. CH 07 遇到报错，照着排障流程走一遍

**结束时你应该能**：打开 dsh、发消息、跑 headless、接第三方模型、看懂基本报错。

### Day 2：理解骨架，搭好能力

**目标**：搞懂"一切皆插件"到底是什么意思，把常用能力接上。

**读什么**：CH 08 → CH 16（PART 02 + PART 03）

**做什么**：
1. CH 08–10 理解插件树、消息流转、会话与轨迹——这三章是理论，不用写代码，看懂就行
2. CH 11 看懂工具调用流水线和权限审批
3. CH 12 接一个 MCP 服务器（比如 Firecrawl），让 Agent 能抓网页
4. CH 13 用一下子代理，体验"派活给别人干"
5. CH 14 装一个 Skill（比如 AIHOT），让 Agent 会用现成能力
6. CH 15 配一个定时任务，让 Agent 每天自动跑一次
7. CH 16 接一个本地模型，体验"不花钱也能用"

**结束时你应该能**：说清 dsh 的插件架构、接 MCP、用子代理、装 Skill、配定时任务、接本地模型。

### Day 3：开发插件，上生产

**目标**：自己写一个插件，知道怎么部署和运维。

**读什么**：CH 17 → CH 23（PART 04）+ CH 27 → CH 29（PART 06）

**做什么**：
1. CH 17 学会装插件、管插件
2. CH 18–21 跟着写四个插件：最小插件、服务、工具、钩子——每一个都跑通
3. CH 22 写一个 UI 插件，在设置页加个 tab
4. CH 23 理解模型适配器（选读，不做插件开发可以跳过）
5. CH 27 用 Docker 把 dsh 部署到服务器，绑域名配 HTTPS
6. CH 28 过一遍安全清单，确认权限和密钥配置没问题
7. CH 29 学会看轨迹、管上下文、控成本

**结束时你应该能**：写一个能跑的插件、部署到服务器、管好安全和成本。

## 三条路的共同起点

不管走哪条，都建议先花十分钟把 CH 00 看完——它只有三个直觉，不涉及任何操作，却是后面所有章节的地基：**Agent = Model + Harness，一切皆插件，为什么是现在**。
