## Objetivo do capítulo

Antes de escrever este capítulo, fiquei em dúvida por muito tempo se realmente valia a pena dedicar tempo para entender de verdade o dsh. O mercado de frameworks de Agent está saturado: mais um ou menos um parece irrelevante. Mas quando coloquei a mão na massa, percebi que o dsh não está na mesma categoria. Não é "mais uma ferramenta de Agent pronta para usar", é um **kit para você mesmo montar o seu próprio Agent**.

Este capítulo não ensina a digitar comandos. Primeiro ele constrói três intuições. Quando essas três coisas se encaixam, cada capítulo seguinte fará sentido:

1. **O que é de fato um Agent** — a fórmula oficial em uma linha: `Agent = Model + Harness`
2. **Por que dizemos "everything is a plugin"** — é esse o significado de "Lego" aqui
3. **Por que justamente agora** — o que aconteceu após o open source de 13 de agosto de 2026

## Prática

### Primeiro passo: copiar a fórmula

A DeepSeek descreve oficialmente o posicionamento do dsh em uma única frase:

```
Agent = Model + Harness
```

Model é o próprio LLM (a família DeepSeek-V4, ou qualquer modelo de terceiros). Só cuida de "pensar". Harness é tudo o que não é o model: ferramentas, prompts, memória, gestão de contexto, planejamento de tarefas, colaboração multi-Agent, MCP, Skill... a casca que faz o modelo **de fato realizar coisas**.

Uma analogia: **o modelo é um bom cavalo, o Harness são as rédeas e os arreios**. Um cavalo sem arreios, por mais rápido que seja, só gira em círculos. Com arreios, você o leva para onde quiser.

Uma linha: **o modelo cuida do pensar, o Harness do trabalhar**.

### Segundo passo: entender "Lego"

A primeira frase do README oficial do dsh diz:

> It uses an architecture where **everything is a plugin**

Tudo é um plugin. Em palavras simples: adaptador de modelo, registro de ferramentas, log de sessão, laço do Agent, UI, memória, scheduler... cada um é um bloco de plugin independente. Você pode escolher, trocar, apagar ou acrescentar em configuração sem tocar numa única linha de código do framework.

Por baixo, roda sobre um sistema de plugins em TypeScript chamado **Cordis** (a equipe diz que vem sendo polido há quatro anos). Por trás de uma única linha de comando do dsh há uma "árvore de plugins" composta por mais de 90 plugins. A figura abaixo mostra sua estrutura:

![Arquitetura da árvore de plugins do dsh (ilustração)](/assets/part00/dsh-arch.svg)

O que prestar atenção nesta figura são apenas duas coisas:

1. **A base é o Cordis** — todos os plugins crescem em cima dele, e o Cordis os administra de forma unificada.
2. **Até o laço principal do Agent é um plugin** — o bloco amarelo fluorescente do centro é exatamente isso. Este é o ponto mais disruptivo: o dsh **não tem núcleo, nem caminho privilegiado**. Quer trocar o laço padrão "pensar-executar"? Não é uma reescrita massiva do framework, é trocar um plugin.

Isso é "Lego": a base é fixa, mas você pode montar qualquer forma. Quer trocar o modelo? Troque um plugin. Quer adicionar ferramentas? Instale um plugin. Quer mudar a UI? Instale um plugin de skin. Por isso se chama "a era Lego do Agent".

### Terceiro passo: ver "por que agora"

Na noite de 13 de agosto de 2026, um novo repositório apareceu silenciosamente sob a organização `deepseek-ai`. A descrição do repo era uma única linha: "Everything is a Plugin." Sem evento de lançamento, sem nota promocional longa; o README chegou a avisar que "haverá mudanças incompatíveis no futuro".

E então os números dispararam (todos de coberturas da mídia na época, não afirmações oficiais):

- **24 horas** após o open source: estrelas ultrapassaram **46.000** (Hacker News no topo)
- **48 horas** após o open source: estrelas ultrapassaram **100.000**
- Em **3 dias**: estrelas passaram de **130.000**, forks perto de 14.000
- Ecossistema de plugins: na noite do lançamento, **288** repositórios de plugin indexados → em poucos dias, repos com a etiqueta `dsh-plugin` passaram de **1.000** → em 5 dias, mais de **6.000**

Por que essa explosão? Porque até então, as "capacidades corporais" do Agent — acesso a arquivos, execução em terminal, chamadas de ferramentas, organização de contexto — estavam **soldadas dentro de produtos fechados** como Claude Code e OpenAI Codex. Quer personalizar? Usar o mecanismo de plugin do fornecedor (limitado pelo alcance dele) ou reinventar a roda do zero. Desta vez, a DeepSeek abriu toda essa camada como open source e a desmontou em blocos Lego.
