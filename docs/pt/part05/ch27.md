## Objetivo do capítulo

Este capítulo mostra como usar o dsh para gerar um vídeo completo. Instalamos um plugin de criação de vídeo Remotion, depois damos um tema e deixamos ele cuidar de tudo, do roteiro à animação às legendas à narração, renderizando por fim para MP4. Depois deste capítulo, você vai saber como pedir ao dsh para fazer vídeos, e como ajustar fino e exportar o primeiro rascunho.

## Qual plugin: dsh-remotion

Este capítulo usa **dsh-remotion** — um plugin de criação de vídeo que porta as skills oficiais do Remotion para o dsh, MIT open source, [repositório no GitHub](https://github.com/STARDUSTLC666/dsh-remotion).

Remotion é um framework para criação programática de vídeos com React — escreva código para gerar animações, legendas, transições, e renderize para MP4 no final. O dsh-remotion registra os 38 arquivos de regras oficiais do Remotion (animação, áudio, legendas, 3D, gráficos, fontes, transições, etc.) no dsh, e após instalar, basta dizer "use Remotion para fazer um vídeo" para acionar.

## Passo 1: instalar o plugin

Desta vez instalamos pelo Mercado de Plugins (dsh-market) instalado no CH 18 — abra Configurações → Mercado de Plugins, busque por remotion, encontre dsh-remotion, clique em instalar:

![Mercado de Plugins busca dsh-remotion](/assets/part05/ch26-install.png)

Depois de clicar em instalar, o Mercado de Plugins mostrará "Instalado", e no topo pede que você reinicie o dsh para fazer efeito — clique em "Reiniciar agora":

![dsh-remotion instalado com sucesso, pede reinício para fazer efeito](/assets/part05/ch26-extra.png)

Depois do reinício, o plugin faz efeito.

> Requisitos de ambiente: Node.js ≥ 20; renderizar vídeo precisa de ffmpeg (Remotion vem com instruções para instalar).

## Passo 2: entender o fluxo de geração de vídeo

Depois da instalação, você pode primeiro pedir ao dsh uma breve introdução do fluxo de fazer vídeos com Remotion, para saber o que esperar. Basta perguntar:

```
Briefly introduce the flow of making videos with Remotion
```

Ele vai te dizer o fluxo típico de fazer vídeos com Remotion: **escrever roteiro e storyboard → criar projeto Remotion → escrever Composition e componentes React → adicionar animação, legendas, áudio → pré-visualizar e debugar → renderizar MP4**. Os conceitos centrais do Remotion são Composition (registra um segmento de vídeo, especifica largura, altura, frame rate, total de frames), Sequence (linha do tempo, arranja componentes por tempo), interpolate / spring (animação), e por fim use `npx remotion render` para gerar a saída.

![dsh apresenta o fluxo de geração de vídeo do Remotion](/assets/part05/ch26-flow.png)

## Passo 3: dar um tema, gerar o vídeo

Antes de fazer um vídeo, decida o tema primeiro. Este capítulo fazemos um vídeo curto: **"Tudo é um Plugin: Introdução de Um Minuto ao DeepSeek Harness"**.

O prompt não precisa ser complexo, basta dar um tema e a duração, o resto do storyboard, roteiro, animação ele planeja sozinho:

```
Use Remotion to make an intro video for me, topic is "Everything is a Plugin: DeepSeek Harness Intro", aimed at developers first encountering dsh.

Requirements:
- Style minimal white, animation demo feel
- With captions and voiceover (Chinese voiceover)
- Include animation effects (text fade-in, element transition)
- Include transition effects (use different transitions between scenes)
- Include charts (e.g. use a simple architecture diagram to show dsh's plugin layers)
- Use monospace font, fits the technical theme
- Finally render to MP4

If missing rendering dependencies like ffmpeg, install them yourself then continue.
```

Envie esta mensagem para o dsh. Ele vai seguir o fluxo do Remotion passo a passo — primeiro escrever o roteiro e storyboard, depois criar um projeto Remotion, escrever componentes React, adicionar animação, legendas e narração, e por fim renderizar.

Abaixo está o resumo do resultado depois da geração — pontos-chave da implementação, estrutura de cinco atos, tecnologias usadas tudo listado claramente:

![Geração completa: resumo da implementação](/assets/part05/ch26-video1.png)

Do envio do prompt até obter o MP4 renderizado, o processo todo levou 36 minutos e 50 segundos — renderizar vídeo é mais lento do que fazer um PPT, porque cada frame precisa ser computado. Isso é só o efeito de dar casualmente um tema — com o plugin solidificando o fluxo, o dsh segue os passos um por um, sem precisar descobrir do zero a cada vez o que fazer primeiro:

![Geração completa: estrutura de cinco atos e tempo gasto](/assets/part05/ch26-video2.png)
