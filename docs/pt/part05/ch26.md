## Objetivo do capítulo

Este capítulo mostra como usar o dsh para gerar um PPT completo. Instalamos um Skill dedicado para PPT, depois damos um briefing e deixamos ele cuidar de tudo, do layout à geração do PPT em versão web, e ainda dá para editar direto no navegador, e exportar um PPTX editável. Depois deste capítulo, você vai saber como pedir ao dsh para fazer apresentações, e como ajustar fino e exportar o primeiro rascunho.

## Qual Skill: dashiai-ppt

Este capítulo usa **dashiai-ppt** — um Skill de PPT para profissionais, open source sob AGPL-3.0, [repositório no GitHub](https://github.com/chuspeeism/dashiAI-ppt-skill).

Suas funcionalidades:

- **12 temas visuais**: soft-skeuomorphism, neon purple-green, código claro/escuro, glass candy, experimento preto-dourado, revista azul-profunda, crescimento alta-energia, etc. Escolha estilos diferentes para tipos diferentes de relatório
- **1020 páginas de layout**: dezenas de gráficos, modelos de análise como SWOT / Cinco Forças de Porter / Business Model Canvas, diagramas de arquitetura, linhas do tempo, galerias de imagem-texto — cada página que você realmente precisa para relatórios tem um layout pronto
- **Editável depois de gerar**: cada página tem um console, mude texto, troque imagens, ajuste a contagem de módulos, mude cores, mudanças gravam de volta no arquivo automaticamente
- **Exportável para PPTX**: não são imagens, mas arquivos PowerPoint reais e editáveis, caixas de texto e gráficos podem ser alterados manualmente
- **Tudo local**: geração, edição e exportação tudo na máquina local, conteúdo não é enviado para servidor

## Passo 1: instalar o Skill

O conteúdo completo deste Skill está no subdiretório `skills/dashiai-ppt/` do repo do GitHub; instalamos pelo jeito "soltar pasta" no diretório de Skill a nível de projeto do dsh `<project-root>/.dsh/skills/`, não pelo comando npx do README.

Basta dizer diretamente ao dsh:

```
Help me install the dashiai-ppt PPT skill; the repo is https://github.com/chuspeeism/dashiAI-ppt-skill, the skill content is in the repo's skills/dashiai-ppt/ subdirectory. Clone this subdirectory to the .dsh/skills/ under the current workspace, and tell me when it's done.
```

O dsh vai clonar o repo sozinho e colocar a pasta do Skill no lugar certo.

![Skill dashiai-ppt instalado com sucesso](/assets/part05/ch25-skill-install.png)

> Requisitos de ambiente: a máquina local precisa rodar Node.js 18+ e npm (dependências instaladas automaticamente na primeira geração); exportar PPTX / PDF precisa de Chrome / Edge instalados localmente.

## Passo 2: entender o fluxo do Skill

Depois da instalação, você pode primeiro pedir ao dsh uma breve introdução do fluxo do Skill, para saber o que esperar. Basta perguntar:

```
Briefly introduce the flow of this skill
```

Ele vai te dizer o fluxo completo: **perguntar estilo → finalizar conteúdo → gerar plano JSON → renderizar HTML → validar aceitação → entregar**. Resumindo: você dá requisitos, ele confirma estilo e assets, gera um plano, renderiza localmente, pré-visualiza e valida, entrega no formato. Totalmente local, funciona offline.

![Introdução ao fluxo do Skill dashiai-ppt](/assets/part05/ch25-step2.png)

## Passo 3: dar um tema, gerar o PPT

Fazer um PPT é flexível: se você já tem material (por exemplo, um documento, um artigo, um conjunto de dados), pode jogar o material direto no dsh e deixar ele fazer um PPT baseado nele; se não tem material pronto, só dar um tema já basta, o dsh planeja a estrutura de conteúdo sozinho e confirma passo a passo.

Aqui demonstramos o método de só tema. Este capítulo fazemos um PPT de compartilhamento sobre **"Tudo é um Plugin: Guia de Introdução ao DeepSeek Harness"**.

```
Use dashiai-ppt to make a PPT for me, topic is "Everything is a Plugin: DeepSeek Harness Getting Started Guide", aimed at developers first encountering dsh.
```

Envie esta mensagem para o dsh. Ele vai seguir o fluxo do Skill para confirmar estilo, número de páginas, estrutura de conteúdo passo a passo, então chamar o gerador para renderizar, e por fim te dar um link de pré-visualização local.

Esse é o benefício de um Skill — ele solidifica o fluxo completo de "fazer um PPT" num conjunto claro de passos, o dsh só segue, sem precisar descobrir do zero a cada vez o que perguntar primeiro e o que fazer em seguida. Abaixo está a geração dele seguindo a especificação do Skill — primeiro confirma o estilo do tema, depois planeja a estrutura do conteúdo, então gera página por página:

![Fluxo de geração 1: confirmar estilo e planejamento de conteúdo](/assets/part05/ch25-gen-flow1.png)

![Fluxo de geração 2: gerar conteúdo página por página](/assets/part05/ch25-gen-flow2.png)

![Fluxo de geração 3: renderização completa e entrega de pré-visualização](/assets/part05/ch25-gen-flow3.png)

Se dependências precisarem ser instaladas durante a geração (por exemplo, npm install na primeira execução), o dsh vai rodá-las em background, sem bloquear o progresso da tarefa principal. A imagem abaixo mostra a conversa principal continuando enquanto dependências são instaladas em background:

![Instalação de dependências em background não bloqueia a tarefa principal](/assets/part05/ch25-bg-install.png)

A razão de você poder ver a execução da tarefa em background aqui é o plugin dsh-better-sidebar instalado no CH 18 — ele expande e mostra proativamente o que o background está fazendo. Sem esse plugin, o dsh ainda rodaria em background e você ainda poderia rastrear pela trajectory, mas não veria o que está acontecendo a menos que olhasse a trajectory ativamente. Com a sidebar, o que o background está fazendo fica claro de uma olhada.

Depois que a geração termina, o dsh te dá uma URL local de pré-visualização, com o resumo do produto anexado — tema, estilo, número de páginas, formato de saída, esboço de páginas tudo listado claramente:

![Geração completa: URL de pré-visualização e resumo do produto](/assets/part05/ch25-extra1.png)

Do envio do prompt até obter um PPT completo de 12 páginas, o processo todo levou 17 minutos e 27 segundos. Isso é só o efeito de dar casualmente um tema — com o Skill solidificando o fluxo, o dsh segue os passos um por um, sem precisar descobrir do zero a cada vez o que fazer primeiro:

![Geração completa: tempo gasto e localização do produto](/assets/part05/ch25-result.png)

Vamos ver quanto custou. Para fazer este PPT, foram 124 requisições de API, 10,61M de tokens, custando ¥1,17:

![Informações de uso da Plataforma Aberta DeepSeek](/assets/part05/ch25-cost.png)

DeepSeek, como modelo nacional, tem preço já bem acessível por si só, somado à tecnologia de alta taxa de cache hit do dsh — em conversas multi-turno, system prompt, configuração de workspace, conversa histórica etc. como prefixo quase não mudam, dá para acertar o cache a cada vez, a parte de input que acerta o cache é cobrada a uma taxa muito menor do que o normal. Combinado, rodar uma tarefa completa de Agent é de custo extremamente baixo, o uso diário não machuca em nada.

## Passo 4: editar no navegador

Depois que a geração termina, o dsh te dá um link web local (parecido com `http://127.0.0.1:número-da-porta/`), abrir no navegador é o editor web do PPT.

Cada página tem um console, você pode:

- **Mudar texto**: clicar em qualquer texto para editar diretamente
- **Trocar imagens**: clicar num slot de imagem para fazer upload de uma substituição
- **Ajustar contagem de módulos**: arrastar o slider para aumentar ou diminuir os módulos na página
- **Mudar layout**: selecionar um layout diferente no console
- **Mudar esquema de cores**: alternar com um clique dentro do estilo
- **Animações de transição de página**: 9 animações de transição para escolher

Mudanças gravam de volta no arquivo automaticamente. Se não estiver satisfeito, mude direto, atualize para ver a versão mais recente.

A imagem abaixo é o editor de PPT aberto no navegador — à esquerda está o diretório de miniaturas das 12 páginas, no centro a página atual, à direita o console, layout de página, animação de transição, cor do tema, contagem de módulos tudo pode ser ajustado diretamente:

![Editor de PPT no navegador](/assets/part05/ch25-extra2.png)

Texto também pode ser editado diretamente online — clicar em qualquer área de texto para mudar, mudanças gravam automaticamente, sem precisar voltar ao dsh para regenerar:

![Editar texto diretamente online](/assets/part05/ch25-export2.png)

## Passo 5: exportar PPTX

Quando satisfeito, no menu de exportação no canto superior direito do navegador, selecione PPTX, e você pode baixar um arquivo PowerPoint real e editável. O menu de exportação também suporta pacote offline HTML e PDF:

![Menu de exportação: HTML / PDF / PPTX](/assets/part05/ch25-export1.png)

Você também pode pedir ao dsh para exportar diretamente:

```
Export the PPT you just generated into a .pptx file, put it in the current workspace, filename deepseek-harness-intro.pptx.
```

O arquivo vai parar no workspace, clique duas vezes para abrir no PowerPoint ou WPS para continuar editando.

## O que você aprendeu neste capítulo

Você passa se conseguir completar os itens abaixo:

- [ ] Instalar o Skill dashiai-ppt no diretório `.dsh/skills/` a nível de projeto

- [ ] Saber como editar diretamente texto, trocar imagens, ajustar layout no editor do navegador
- [ ] Exportar o arquivo `.pptx` e abrir com PowerPoint
