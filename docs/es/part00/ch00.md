## Objetivo del capítulo

Antes de escribir este capítulo, dudé durante mucho tiempo si realmente valía la pena tomarse el tiempo de entender de verdad dsh. El mercado de frameworks de Agent está saturado: uno más o uno menos parece irrelevante. Pero al ponerme manos a la obra descubrí que dsh no pertenece a la misma categoría. No es "una herramienta de Agent lista para usar más", sino un **kit para que tú mismo ensambles tu Agent**.

Este capítulo no te enseña a teclear comandos. Primero construye tres intuiciones. Cuando estas tres cosas encajen, cada capítulo posterior tendrá sentido:

1. **Qué es en realidad un Agent** — la fórmula oficial en una línea: `Agent = Model + Harness`
2. **Por qué decimos "everything is a plugin"** — eso es lo que aquí significa "Lego"
3. **Por qué precisamente ahora** — qué ocurrió tras el open source del 13 de agosto de 2026

## Práctica

### Primer paso: copiar la fórmula

DeepSeek describe oficialmente el posicionamiento de dsh en una sola frase:

```
Agent = Model + Harness
```

Model es el LLM en sí (la familia DeepSeek-V4, o cualquier modelo de terceros). Solo se encarga de "pensar". Harness es todo lo demás: herramientas, prompts, memoria, gestión de contexto, planificación de tareas, colaboración multi-Agent, MCP, Skill... la cáscara que permite al modelo **realmente hacer cosas**.

Una analogía: **el modelo es un buen caballo, el Harness son las riendas y los arreos**. Un caballo sin arreos, por rápido que sea, solo gira en círculos. Con arreos, puedes llevarlo donde quieras.

Una línea: **el modelo se encarga de pensar, el Harness de trabajar**.

### Segundo paso: entender "Lego"

La primera frase del README oficial de dsh dice:

> It uses an architecture where **everything is a plugin**

Todo es un plugin. Dicho en llano: adaptador de modelo, registro de herramientas, log de sesión, bucle del Agent, UI, memoria, scheduler... cada uno es un bloque de plugin independiente. Puedes elegirlos, intercambiarlos, eliminarlos o añadirlos en configuración sin tocar una sola línea de código fuente del framework.

Por debajo corre sobre un sistema de plugins en TypeScript llamado **Cordis** (el equipo dice que lo llevan puliendo cuatro años). Detrás de una sola línea de comando de dsh hay un "árbol de plugins" compuesto por más de 90 plugins. La figura de abajo muestra su estructura:

![Arquitectura del árbol de plugins de dsh (ilustración)](/assets/part00/dsh-arch.svg)

Lo que hay que mirar en esta figura son solo dos cosas:

1. **La base es Cordis** — todos los plugins crecen encima de él, y Cordis los administra de forma unificada.
2. **Incluso el bucle principal del Agent es un plugin** — el bloque amarillo fluorescente del centro es exactamente eso. Este es el punto más disruptivo: dsh **no tiene núcleo, ni ruta privilegiada**. ¿Quieres reemplazar el bucle por defecto "pensar-ejecutar"? No es una reescritura del framework, es cambiar un plugin.

Esto es "Lego": la base es fija, pero puedes construir cualquier forma. ¿Quieres cambiar el modelo? Cambia un plugin. ¿Quieres añadir herramientas? Instala un plugin. ¿Quieres cambiar la UI? Instala un plugin de skin. Por eso se llama "la era Lego del Agent".

### Tercer paso: ver "por qué ahora"

La noche del 13 de agosto de 2026, un nuevo repositorio apareció silenciosamente bajo la organización `deepseek-ai`. La descripción del repo era una sola línea: "Everything is a Plugin." Sin evento de lanzamiento, sin nota promocional larga; el README incluso advertía que "habrá cambios incompatibles en el futuro".

Y entonces las cifras se volvieron locas (todas de coberturas de medios del momento, no afirmaciones oficiales):

- **24 horas** tras el open source: las estrellas superaron las **46.000** (Hacker News top 1)
- **48 horas** tras el open source: las estrellas superaron las **100.000**
- A los **3 días**: más de **130.000** estrellas, cerca de 14.000 forks
- Ecosistema de plugins: en la noche de lanzamiento se indexaron **288** repositorios de plugin → en pocos días los repos con la etiqueta `dsh-plugin` superaron los **1.000** → a los 5 días, más de **6.000**

¿Por qué explotó así? Porque hasta entonces, las "capacidades corporales" del Agent —acceso a archivos, ejecución en terminal, llamadas a herramientas, organización del contexto— estaban **soldadas dentro de productos de código cerrado** como Claude Code u OpenAI Codex. ¿Querías personalizar? Usar el mecanismo de plugins del proveedor (limitado por su alcance) o construir la rueda desde cero. Esta vez DeepSeek abrió toda esa capa como open source y la rompió en bloques Lego.
