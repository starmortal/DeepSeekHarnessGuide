## Objetivo del capítulo

Este capítulo te guía en el uso de dsh para generar un PPT completo. Instalamos un Skill específico para PPT, luego le das un brief, y se encarga de todo: del outline al layout, hasta generar la versión web del PPT. Incluso puedes editar directamente en el navegador y exportar un PPTX editable. Tras este capítulo, sabrás cómo hacer que dsh te ayude a hacer presentaciones y cómo ajustar y exportar el primer borrador.

## Qué Skill: dashiai-ppt

Este capítulo usa **dashiai-ppt** — un Skill de PPT pensado para profesionales, open-source AGPL-3.0, [repo en GitHub](https://github.com/chuspeeism/dashiAI-ppt-skill).

Sus características:

- **12 temas visuales**: soft-skeuomorphism, neón morado-verde, código claro/oscuro, glass candy, experimento blanco-y-negro, revista azul profundo, high-energy growth, etc. Elige diferentes estilos según el tipo de informe
- **1020 páginas-layout**: decenas de gráficos, modelos de análisis como SWOT / Cinco Fuerzas de Porter / Business Model Canvas, diagramas de arquitectura, timelines, galerías imagen-texto — cada página que necesitas de verdad para un informe tiene un layout listo
- **Editable tras generar**: cada página trae una consola, cambia texto, intercambia imágenes, ajusta el número de módulos, cambia colores; los cambios se autoguardan en el archivo
- **Exportable a PPTX**: no son imágenes, sino archivos PowerPoint reales editables, los cuadros de texto y los gráficos se pueden cambiar a mano
- **Todo local**: generación, edición y exportación suceden en la máquina local; el contenido no se sube al servidor

## Paso 1: Instala el Skill

El contenido completo de este Skill está en el subdirectorio `skills/dashiai-ppt/` del repo de GitHub; lo instalamos con el método de "soltar la carpeta" en el directorio de Skill a nivel de proyecto de dsh, `<raíz-del-proyecto>/.dsh/skills/`, no con el comando npx del README.

Solo di directamente en dsh:

```
Help me install the dashiai-ppt PPT skill; the repo is https://github.com/chuspeeism/dashiAI-ppt-skill, the skill content is in the repo's skills/dashiai-ppt/ subdirectory. Clone this subdirectory to the .dsh/skills/ under the current workspace, and tell me when it's done.
```

dsh clonará el repo por sí mismo y dejará la carpeta del Skill en el lugar correcto.

![dashiai-ppt skill instalado correctamente](/assets/part05/ch25-skill-install.png)

> Requisitos de entorno: la máquina local debe correr Node.js 18+ y npm (las dependencias se autoinstalan en la primera generación); exportar a PPTX / PDF requiere Chrome / Edge instalados localmente.

## Paso 2: Entiende el flujo de trabajo del Skill

Tras la instalación, puedes pedirle a dsh que te haga una breve introducción del flujo del Skill, para saber qué esperar. Solo pregunta:

```
Briefly introduce the flow of this skill
```

Te dirá el flujo de trabajo completo: **preguntar estilo → fijar contenido → generar plan JSON → renderizar HTML → validar aceptación → entregar**. En resumen: tú das los requisitos, confirma estilo y assets, genera un plan, renderiza localmente, previsualiza y valida, entrega en el formato. Totalmente local, usable sin conexión.

![Introducción al flujo de dashiai-ppt skill](/assets/part05/ch25-step2.png)

## Paso 3: Da un tema y genera el PPT

Hacer un PPT es flexible: si ya tienes material (por ejemplo, un documento, un artículo, un conjunto de datos), puedes lanzarle el material directamente a dsh y que haga un PPT basado en ese material; si aún no tienes material listo, basta con dar un tema, dsh planificará por sí mismo la estructura del contenido y la confirmará paso a paso.

Aquí demostramos el método de solo tema. En este capítulo hacemos un PPT para una charla sobre **"Todo es un plugin: guía de inicio de DeepSeek Harness"**.

```
Use dashiai-ppt to make a PPT for me, topic is "Everything is a Plugin: DeepSeek Harness Getting Started Guide", aimed at developers first encountering dsh.
```

Envía este mensaje a dsh. Seguirá el flujo del Skill para confirmar paso a paso el estilo, el número de páginas y la estructura del contenido; luego invocará al generador para renderizar y, por último, te dará un enlace de preview local.

Esta es la ventaja de un Skill — solidifica el flujo completo de "hacer un PPT" en un conjunto claro de pasos; dsh simplemente los sigue, sin tener que idear desde cero cada vez qué preguntar primero y qué hacer después. Debajo está su generación siguiendo la spec del Skill — primero confirma el tema de estilo, luego planifica la estructura de contenido, luego genera página a página:

![Flujo de generación 1: confirmar estilo y planificar contenido](/assets/part05/ch25-gen-flow1.png)

![Flujo de generación 2: generar contenido página a página](/assets/part05/ch25-gen-flow2.png)

![Flujo de generación 3: renderizado completo y preview entregado](/assets/part05/ch25-gen-flow3.png)

Si durante la generación hace falta instalar dependencias (por ejemplo, `npm install` en la primera ejecución), dsh las lanza en background sin bloquear el progreso de la tarea principal. La imagen de abajo muestra la conversación principal continuando mientras las dependencias se instalan en background:

Que aquí se vea el avance de la tarea de background se debe al plugin dsh-better-sidebar instalado en CH 17 — se expande automáticamente y muestra proactivamente lo que está pasando en background. Con el sidebar, lo que el background hace queda claro de un vistazo.

Cuando termina la generación, dsh te da una URL de preview local con el resumen del producto adjunto — tema, estilo, número de páginas, formato de salida, outline de páginas, todo claramente listado:

Desde enviar el prompt hasta obtener un PPT completo de 12 páginas, todo el proceso tardó 17 minutos y 27 segundos. Esto es solo el efecto de darle un tema a la ligera — con el Skill solidificando el flujo, dsh sigue los pasos uno a uno, sin tener que idear desde cero cada vez qué hacer primero:

![Generación completada: tiempo invertido y ubicación del producto](/assets/part05/ch25-result.png)

Veamos cuánto costó. Para hacer este PPT hubo 124 peticiones a la API, 10,61 M de tokens, con un coste de ¥1,17:

![Información de uso en la plataforma abierta de DeepSeek](/assets/part05/ch25-cost.png)

DeepSeek, como modelo doméstico, ya de por sí tiene precios muy asequibles; sumado a la alta tasa de acierto de caché de dsh — en conversaciones multi-turno, el system prompt, la config del workspace, el historial de diálogo, etc., como prefijo casi no cambian, pueden acertar la caché cada vez, y la parte acertada del input se factura a una tarifa mucho menor que la normal. Combinado, correr una tarea completa de Agent tiene un coste extremadamente bajo, el uso diario no duele en absoluto.

## Paso 4: Edita en el navegador

Cuando termina la generación, dsh te da un enlace web local (similar a `http://127.0.0.1:número-de-puerto/`); abrirlo en un navegador es el editor web del PPT.

Cada página trae una consola; puedes:

- **Cambiar texto**: haz clic en cualquier texto para editarlo directamente
- **Cambiar imágenes**: haz clic en un slot de imagen para subir un reemplazo
- **Ajustar el número de módulos**: arrastra el slider para aumentar o reducir los módulos de la página
- **Cambiar layout**: selecciona un layout diferente en la consola
- **Cambiar la paleta**: cambia con un clic dentro del estilo
- **Animaciones de transición de página**: 9 animaciones de transición a elegir

Los cambios se autoguardan en el archivo. Si no quedas conforme, cámbialo directamente y refresca para ver lo último.

La imagen de abajo es el editor del PPT abierto en el navegador — a la izquierda el índice de miniaturas de las 12 páginas, en el centro la página actual, a la derecha la consola; el layout de la página, la animación de transición, el color del tema y el número de módulos se ajustan directamente:

![Editor del PPT en el navegador](/assets/part05/ch25-extra2.png)

El texto también se puede editar directamente online — haz clic en cualquier área de texto para cambiarla, los cambios se autoguardan, sin necesidad de volver a dsh para regenerar:

![Edita texto directamente online](/assets/part05/ch25-export2.png)

## Paso 5: Exporta PPTX

Cuando estés conforme, en el menú de exportación de la esquina superior derecha del navegador, elige PPTX y podrás descargar un archivo PowerPoint real editable. El menú de exportación también soporta paquete offline HTML y PDF:

![Menú de exportación: HTML / PDF / PPTX](/assets/part05/ch25-export1.png)

También puedes pedirle a dsh que exporte directamente:

```
Export the PPT you just generated into a .pptx file, put it in the current workspace, filename deepseek-harness-intro.pptx.
```

El archivo caerá en el workspace; haz doble clic para abrirlo en PowerPoint o WPS y seguir editando.
